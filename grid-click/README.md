# Grid Click

Ubuntu 26.04 / GNOME 50 / Wayland에서 화면 격자를 키보드로 좁혀 클릭하는 독립 프로그램입니다.
앱의 접근성 정보나 좌표를 읽지 않고 GNOME Shell의 실제 화면 좌표를 사용합니다. VSCode·Chromium 실행 옵션, AT-SPI, Python 컨트롤러가 필요하지 않습니다.

## 설치

이 폴더에서 일반 사용자로 실행합니다.

```bash
./install.sh
```

설치 후 **로그아웃하고 다시 로그인**하세요. 업데이트도 같은 절차입니다.
필요한 배포판 패키지가 없으면 설치 스크립트가 sudo로 설치합니다. 스크립트 자체에는 sudo를 붙이지 마세요.
실행에 필요한 패키지는 `gnome-shell`, `gjs`, `libglib2.0-bin`입니다.

기존 HAP와 별도 확장(`grid-click@local`)이며 단축키도 다릅니다. 기존 프로그램을 삭제할 필요는 없습니다.

## 사용

1. 클릭할 화면을 열고 **Super+Shift+G**를 누릅니다. 활성 창이 있는 모니터에서 시작합니다.
2. 목표가 있는 칸의 문자를 누릅니다. 선택한 칸이 다시 9칸으로 나뉩니다. 원하는 정밀도까지 반복합니다.
3. 빨간 십자 중심이 실제 클릭 지점입니다. 필요하면 방향키로 조정한 뒤 클릭합니다.

좌측 상단 도움말은 기본적으로 숨겨져 있습니다. 격자가 열린 상태에서 **?**(보통 Shift+/)를 누르면 표시되고, 다시 누르면 숨겨집니다. 격자를 새로 열 때는 항상 숨긴 상태로 시작합니다.

```text
Q W E
A S D
Z X C
```

| 키 | 동작 |
| --- | --- |
| Q W E / A S D / Z X C | 해당 영역으로 좁히기 |
| Enter | 왼쪽 한 번 클릭 |
| Space | 왼쪽 더블클릭 — 폴더 열기 등 |
| R | 오른쪽 클릭 |
| 방향키 | 클릭 지점 1 논리 픽셀 이동 |
| Shift+방향키 | 10 논리 픽셀 이동 |
| Backspace | 한 단계 되돌리기 |
| Home | 현재 모니터 전체로 되돌리기 |
| Tab | 다음 모니터로 전환 |
| Esc | 클릭 없이 종료 |
| ? | 도움말 표시/숨기기 |

글자는 명령 키이므로 텍스트 입력란은 없습니다. 격자가 작아지면 글자 표시는 사라지지만 같은 키로 계속 좁힐 수 있습니다.
큰 화면은 보통 3~5회 선택 후 클릭하면 됩니다. 격자가 열려 있을 때 마우스를 누르면 취소됩니다.
클릭 전에 격자와 키보드 점유를 해제합니다. 클릭 도중 마우스를 직접 움직이거나 화면 구성이 바뀌면 남은 클릭을 취소합니다.
한글 입력 상태에서는 QWERTY 물리 키 위치도 인식하도록 처리했습니다.

이 프로그램은 버튼을 자동으로 찾지 않습니다. 드래그·스크롤 기능은 포함하지 않습니다.
격자를 띄운 동안 아래 앱의 화면이 움직이면 목표 위치를 다시 선택하세요. 잠금 화면에서는 실행하지 않습니다.

## 설치 위치와 삭제

설치 위치는 `${XDG_DATA_HOME:-$HOME/.local/share}/gnome-shell/extensions/grid-click@local`입니다.
접근성 설정이나 다른 앱의 실행 설정은 변경하지 않습니다.

```bash
./uninstall.sh
```

삭제 후 로그아웃·재로그인하면 실행 중이던 확장도 완전히 내려갑니다.

단축키 변경:

```bash
gsettings --schemadir "${XDG_DATA_HOME:-$HOME/.local/share}/gnome-shell/extensions/grid-click@local/schemas" \
  set org.gnome.shell.extensions.grid-click show-grid "['<Super><Shift>g']"
```

## 개발·검증

```bash
./test.sh
./integration.sh
```

`test.sh`는 분할·되돌리기·모니터 전환·음수 원점·미세 이동·소수점 경계와 문법·스키마·스테이징 설치를 검사합니다.
`integration.sh`는 `.build/`의 독립 설정과 D-Bus, 가상 모니터 두 개를 가진 headless GNOME Wayland 세션을 사용합니다.
**접근성을 끈 GTK 앱**에서 단축키부터 실제 왼쪽/더블/오른쪽 클릭 수와 좌표까지 확인합니다. 테스트용 D-Bus 입력 인터페이스는 설치본에 포함되지 않습니다.
통합 테스트에는 `python3`, `python3-gi`, `gir1.2-gtk-4.0`, `dbus-daemon`, `dbus-bin`이 추가로 필요합니다.
테스트 로그와 격자 스크린샷은 `.build/integration.*/`에 저장됩니다.

다른 GNOME 버전·데스크톱은 지원 대상으로 선언하지 않았습니다. 실제 fractional scaling 환경과 특수한 키보드 배열은 별도 확인이 필요합니다.

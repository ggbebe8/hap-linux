# 터치 제스처 간단 사용설명서

## 한 번에 설치 · 자동 실행

먼저 실행 중인 `try.sh`를 `Ctrl+C`로 종료하고, 프로젝트 폴더에서 실행하세요.

```bash
./install.sh
```

필요한 Ubuntu 패키지, 재부팅 후에도 적용되는 장치 권한, 중앙 UI 확장, 로그인 자동 실행을 설정하고 바로 시작합니다. 필요한 단계에서만 관리자 비밀번호를 요청하므로 명령 앞에 `sudo`를 붙이지 마세요.

**첫 설치는 실제 동작 모드**입니다. 화면 크기 설정 없이 `try.sh`와 같은 감도로 사용할 수 있습니다. UI 적용을 위한 로그아웃 안내가 나오면 로그아웃 후 다시 로그인하세요. 이후에는 터미널을 열지 않아도 로그인할 때 실행됩니다.

```bash
./install.sh --dry-run  # 실제 동작 없이 인식만 하는 자동 실행으로 설치/전환
./install.sh --execute  # 실제 동작 모드로 설치/전환
```

## 업데이트와 관리

수정한 프로젝트에서 `./install.sh`를 다시 실행하면 업데이트됩니다. **기존 제스처와 설정은 보존**합니다. `--execute`나 `--dry-run`으로 모드를 바꾸면 기존 설정을 `.bak` 파일로 백업합니다.

설치 후 제스처를 바꿀 파일은 `~/.config/touchgesture/config.yaml`입니다. 프로젝트의 기본 설정 파일만 바꿔서는 이미 설치된 서비스에 반영되지 않습니다. 업데이트로 추가된 제스처도 사용자 설정에 직접 추가하세요.

| 목적 | 명령 |
|---|---|
| 설정 편집 | `nano ~/.config/touchgesture/config.yaml` |
| 설정 문법 확인 | `~/.local/bin/touchgesture --check-config` |
| 설정 변경 적용 | `systemctl --user restart touchgesture` |
| 상태 확인 | `systemctl --user status touchgesture` |
| 잠시 중지 | `systemctl --user stop touchgesture` |
| 다시 시작 | `systemctl --user start touchgesture` |
| 자동 실행 끄고 중지 | `systemctl --user disable --now touchgesture` |
| 자동 실행 켜고 시작 | `systemctl --user enable --now touchgesture` |
| 최근 오류 보기 | `journalctl --user -u touchgesture -n 50 --no-pager` |

`stop`은 현재 실행만 멈추므로 다음 로그인에는 다시 시작됩니다. 계속 꺼두려면 `disable --now`를 사용하세요. 서비스와 `try.sh`를 동시에 실행하면 동작이 중복될 수 있으니 하나만 사용하세요. 인식 문제를 조사할 때만 `--debug`를 켜면 평소 CPU 부하와 로그를 줄일 수 있습니다.

## 삭제

```bash
./uninstall.sh          # 앱·자동 실행·확장·자동 권한 설정 삭제, 사용자 설정 보존
./uninstall.sh --purge  # 위 항목과 사용자 설정·설정 백업까지 삭제
```

프로젝트 폴더와 다른 앱도 사용할 수 있는 Ubuntu 패키지는 남깁니다. 다시 쓰려면 `./install.sh`를 실행하세요. 설정을 보존했다면 재설치 시 그대로 사용합니다.

## 실행과 종료

프로젝트 폴더에서 실행합니다. `sudo`는 붙이지 않습니다.

```bash
./try.sh             # 인식만 테스트 (동작 실행 안 함)
./try.sh --execute   # 실제 동작 실행
```

종료는 터미널에서 `Ctrl+C`입니다. 동작은 현재 선택된 앱에 전달됩니다.

## 기본 제스처

| 손가락 | 이동 순서 | 동작 | 단축키 |
|---|---|---|---|
| 하나 | 아래 → 오른쪽 `↓→` | 탭 닫기 | Ctrl+W |
| 하나 | 위 → 오른쪽 `↑→` | 다음 탭 | Ctrl+Tab |
| 하나 | 위 → 왼쪽 `↑←` | 이전 탭 | Ctrl+Shift+Tab |
| 둘 | 함께 아래로 `↓` | 현재 창 닫기 | Alt+F4 |

손가락을 대고 방향을 꺾어 그린 뒤, 1.5초 안에 떼세요. 두 손가락은 거의 동시에 대고 함께 내립니다. 화면 회전은 자동으로 반영됩니다. 단축키의 실제 동작은 앱에 따라 다를 수 있습니다.

화면 중앙에 화살표와 동작 이름이 보이면 손을 뗄 때 해당 동작이 실행됩니다. 추가로 움직여 경로가 달라지면 미리보기가 사라지고 취소됩니다. 테스트 모드에서는 카드가 보여도 실행하지 않습니다.

## 제스처·동작 바꾸기

`try.sh`로 실행할 때는 [src/touchgesture/default.yaml](src/touchgesture/default.yaml)의 `gestures:` 아래 항목을 수정합니다.

```yaml
  - name: previous_tab
    label: 이전 탭
    sequence: [UP, LEFT]
    action:
      type: key
      keys: [CTRL, SHIFT, TAB]
```

- `name`: 겹치지 않는 내부 이름
- `label`: 카드에 표시할 이름
- `sequence`: 이동 순서. `UP` 위, `DOWN` 아래, `LEFT` 왼쪽, `RIGHT` 오른쪽
- `keys`: 함께 누를 단축키
- `fingers: 2`: 두 손가락으로 지정. 생략하면 한 손가락

예를 들어 **아래 → 왼쪽으로 닫은 탭 다시 열기**를 추가하려면 기존 목록 끝에 다음을 붙입니다. 들여쓰기는 다른 항목과 동일하게 맞추고 탭 대신 공백을 사용하세요.

```yaml
  - name: reopen_tab
    label: 닫은 탭 열기
    sequence: [DOWN, LEFT]
    action:
      type: key
      keys: [CTRL, SHIFT, T]
```

명령을 실행하려면 해당 항목의 `action:` 부분을 다음처럼 바꿉니다.

```yaml
    action:
      type: command
      command: "nautilus"
```

저장 후 `Ctrl+C`로 프로그램을 종료하고 다시 실행하면 적용됩니다. **제스처·동작 설정 변경에는 로그아웃이 필요 없습니다.**

## UI와 문제 확인

```bash
./try.sh --execute --no-preview   # 중앙 카드 없이 실행
./try.sh --debug                 # 인식 상세 로그 확인
```

확장 UI를 업데이트한 뒤 이전 모양이 계속 보이면 **로그아웃 후 다시 로그인**하세요. 프로그램 재실행만으로는 GNOME에 남아 있는 이전 확장 코드가 교체되지 않습니다.

## 자동 실행 서비스로 설치한 경우

`install.sh`로 설치한 서비스는 기본적으로 `~/.config/touchgesture/config.yaml`을 사용합니다. 이 파일을 수정한 뒤 다음 명령으로 적용합니다.

```bash
systemctl --user restart touchgesture
```

서비스가 동작 중일 때 `try.sh`를 따로 시험하려면 중복 실행을 피하도록 먼저 중지하세요.

```bash
systemctl --user stop touchgesture
```

서비스 설정의 `dry_run: true`는 테스트, `dry_run: false`는 실제 실행입니다. 사용자 설정에 `gestures:`를 작성하면 기본 제스처 목록 전체를 대체하므로 유지할 항목도 함께 넣어야 합니다.

자세한 설치·설정은 [README.md](README.md)를 참고하세요.
